## Стек

- Next.js 14 (App Router, `output: 'export'`)
- React 18, TypeScript, Tailwind CSS
- GSAP — превью, маски текста, оверлей

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
```
